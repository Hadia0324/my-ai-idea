
# My AI Idea

## Summary
My AI idea is to make a friendly AI helper that talks to people in simple language. It will help students learn, answer their questions, and give them ideas for study. My goal is to make learning easy and fun for everyone.

## How it works
My project has a Python file called hello-ai.py. When you run it, it asks for your name and your AI idea. Then it talks to you and shows your idea back.

## What I learned
I learned how to use GitHub, how to write Python code, and how to submit my AI project for peer review.
